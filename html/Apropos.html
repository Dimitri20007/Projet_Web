Description du projet

Ce site web a été développé dans le cadre du cours de développement web de l'EFREI. Il s'agit d'une vitrine présentant le département informatique de l'école.

Le projet utilise HTML, CSS et JavaScript natif, avec un focus sur les bonnes pratiques UX/UI et l'accessibilité. Il démontre notre maîtrise des technologies web fondamentales et notre capacité à créer des interfaces utilisateurs modernes et ergonomiques.

Technologies utilisées

HTML, CSS, JavaScript natif
