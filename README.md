# Projet_Web

Site vitrine réalisé dans le cadre d’un projet web étudiant. Le site présente plusieurs pages liées à une école/formation, avec une mise en page simple et des interactions JavaScript pour rendre la navigation plus vivante.

## Fonctionnalités JavaScript

- Carrousel sur la page d’accueil pour faire défiler les contenus mis en avant.
- Animations d’apparition au scroll pour afficher certaines sections progressivement.
- Fenêtre modale sur la page À propos pour ouvrir et fermer un contenu de présentation.
- Cartes interactives sur les pages Équipe et Formation, avec retournement au clic et au clavier.
- Mise à jour dynamique du contenu de la page Formation selon la formation sélectionnée.
- Petit chatbot d’aide sur la page Formation, avec réponses locales de secours si besoin.
- Gestion simple de l’état de connexion dans le menu via le stockage local du navigateur.
- Formulaire d’inscription / connexion / mot de passe oublié géré côté client pour la maquette.

## Pages du site

- Accueil
- À propos
- Équipe
- Formation
- Register

## Lancer le projet

Le projet peut être ouvert directement dans un navigateur via un serveur local simple.

1. Ouvrir le dossier du projet dans VS Code.
2. Lancer la page HTML de ton choix, par exemple `html/Accueil.html`, avec Live Server ou un serveur local équivalent.
3. Naviguer entre les pages pour tester les interactions JavaScript.
